```
python tools/probe_llm_capability.py --engine universal
```

4. 同时确认旧 key 已被厂商控制台**吊销**（只换本地文件不算轮换 ——
   泄露出去的那把如果还是有效的，换本地等于没换）。

### 可判定判据

- 探针输出里**不再出现** `401` / `403`（`429` 允许出现：那是额度，不是身份）
- 探针的能力探测项通过数与轮换前一致或多于（当前基线：**5/6 通过、1 失败**）
- 厂商控制台里那把旧 key 显示 **Revoked / Deleted**
- `config.yaml` 仍被 git 忽略（`git check-ignore config.yaml` 返回 0）——
  轮换不该把新 key 带进 git 历史

### 为什么这一项 AI 做不了

生成/吊销 key 需要在厂商控制台登录并操作账号，AI 没有该权限；
而且「旧 key 是否已吊销」这件事的**唯一权威判据在厂商侧**，
本地无论怎么测都只能证明「新 key 能用」，证明不了「旧 key 已废」。
这两件是不同的命题，不能互相替代。
