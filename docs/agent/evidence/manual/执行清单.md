## 三、6 条场景（逐条做，做完再下一条）

### M1 搜索文件

- **先说**：「找一下桌面上的 PDF 文件」
- **看什么**：
  - [ ] 确认语 **≤1.5s** 先出声/出气泡
  - [ ] 随后报出 **2 个**：`验收报告.pdf`、`验收合同_2025.pdf`
  - [ ] 没有把 `验收笔记.txt` / `验收截图_*.png` 报进来
- **证据文件**（放 `docs/agent/evidence/manual/`）：
  - [ ] `M1-搜索-结果气泡.png`（整个欣雅窗口，气泡文字要能看清）
- **失败时抓**：控制台 `[ASR]` 转写行 + `ack:`/`result:` 的 `elapsed_ms` + 截图

### M2 删除确认（P0 最关键）

- **先说**：先说「删除桌面上的验收截图」，**看预览**，再「确定」
- **看什么**：
  - [ ] 预览里列的是 **`验收截图_01.png`、`验收截图_02.png`**（不是 PDF、不是 txt）
  - [ ] 说「确定」后回答已移到回收站
  - [ ] 去回收站能看到这两个 PNG
- **证据文件**（放 `docs/agent/evidence/manual/`）：
  - [ ] `M2-删除-预览气泡.png`（**预览里的文件名必须看得清**）
  - [ ] `M2-删除-回收站核实.png`
- **失败时抓**：预览截图 + 控制台 `route:`（看 `pattern` 是否为空）+ `confirm:` 行 + 审计库记录

### M3 打断

- **先说**：说「找一下所有文件」，**刚开始播报时立刻按打断热键**
- **看什么**：
  - [ ] 播报**当场停住**
  - [ ] 之后**不再**冒出结果播报
  - [ ] 宠物没卡死，随后对话正常
- **证据文件**（放 `docs/agent/evidence/manual/`）：
  - [ ] `M3-打断-现象.mp4`（录屏最直接；不便录屏就 `M3-打断-说明.txt`，写清看到什么 + 贴控制台）
- **失败时抓**：控制台 `[interrupt]` 行 + 打断前后的 `feedback.result` 行

### M4 降级路径

- **先说**：先说「给我讲个笑话」，再说「你好呀」
- **看什么**：
  - [ ] 两句都走**闲聊**
  - [ ] **没有**任何文件操作/截屏/弹确认框
  - [ ] 语气自然
- **证据文件**（放 `docs/agent/evidence/manual/`）：
  - [ ] `M4-降级-笑话.png`
  - [ ] `M4-降级-问候.png`
- **失败时抓**：控制台 `route:` 行（`action` 不是 `chat` 就是误判）+ 截图

### M5 安全边界

- **先说**：说「打开 C 盘 Windows 文件夹」
- **看什么**：
  - [ ] **明确拒绝**，理由对用户可读
  - [ ] 系统目录**没有被打开**
  - [ ] 审计库里有这条拒绝记录
- **证据文件**（放 `docs/agent/evidence/manual/`）：
  - [ ] `M5-安全-拒绝气泡.png`
  - [ ] `M5-安全-审计记录.txt`
- **失败时抓**：控制台 `safety:`/`reject:` 行 + 审计查询结果

### G1 GUI 观察点（与上面 5 条**同时**看即可，不用单独做）

| # | 看什么 | 是/否 |
|---|--------|-------|
| 1 | 说话时宠物**动了**（待机/思考/说话状态切换） | [ ] |
| 2 | 确认气泡位置不挡视线、字看得清 | [ ] |
| 3 | 气泡**自动消失**，不会一直挂着 | [ ] |
| 4 | 播报与口型/动作**大致**同步 | [ ] |
| 5 | 长时间不操作后回到待机，不僵在某个姿势 | [ ] |

证据：`G1-动效-<描述>.mp4`（10~20 秒录屏足够）或 `G1-动效-说明.txt`

> 1/4/5 是**主观项**：看着别扭就记「否」并写一句原因 —— 主观项的价值就在这里。

## 六、有一条特别提醒（安全类）

**M2 如果预览里出现了沙箱以外的文件（尤其是你自己的文件），立刻说「不用了」**，
然后把「预览混进无关文件」当成**发现**记下来。
那是一个真实缺陷，比「删对了」更值得报告。

> 沙箱是为了让「删除截图」不会命中你真桌面上的截图 ——
> 规则路由把「截图」映射成通配符 `*截图*`，在真桌面上会同时命中你自己的文件。
