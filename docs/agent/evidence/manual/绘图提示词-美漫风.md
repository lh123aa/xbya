# 绘图提示词 —— 欧美漫画风 · 上半身

> **用途**：拿去 AI 绘图工具生成桌宠形象的上半身立绘。
> **产出的图怎么用**：见 `精灵图交接规格.md`；本文件只管「怎么画出来」。

---

## 一、先说一个必须处理的冲突

**欧美漫画的招牌技法是密集排线和网点（halftone）**，
但这些是**高频细节**，而桌宠里这张图最终要**缩到 128×128 显示**。
实测：现有精灵图的角色只有 **52×96 像素**。

高频排线缩到这个尺寸会发生什么：

| 原图特征 | 缩到 128px 后 |
|---------|--------------|
| 细密交叉排线 | 糊成一片**脏灰** |
| 网点（halftone dots） | 变成**摩尔纹**（一圈圈波纹） |
| 发丝级细线 | 断线、看不见 |
| 锐利细线稿 | 变粗、糊边 |

**所以要的是「美漫的造型与配色」，不是「美漫的排线技法」**：

- ✅ 要：**大块平面色 + 硬边阴影（cel shading）**、粗轮廓线、夸张的体块概括
  —— 参考 Mike Mignola（《地狱男爵》）、Bruce Timm（《蝙蝠侠动画版》）、
  美式动画角色设计稿
- ❌ 不要：Jim Lee 那种密集交叉排线、四色印刷网点、写实厚涂

这两者**都是欧美漫画风**，区别只在技法密度。选前者，图才能用。

## 二、配色（已在照片取色基础上做美漫化调整）

| 变量 | HEX | 可信度 | 说明 |
|------|-----|--------|------|
| `hair_base` | `#1C1618` | ✔ 量出 | 底色，保持不变（照片里就是近黑） |
| `hair_solid` | `#0E0B0C` | ~ 参考 | **实心暗部**（美漫的大块黑），比底色再压暗 |
| `hair_hi` | `#5A6B7A` | ~ 调整 | 高光**改冷蓝灰** —— 美漫头发高光常用冷色，暖褐会显得像日漫 |
| `skin` | `#E8C9B8` | ✔ 量出 | 比原取值略提亮，为了与黑发拉开对比 |
| `skin_shadow` | `#B98F7E` | ~ 调整 | 阴影**偏冷偏红**，不做暖褐 |
| `skin_black` | `#3A2A26` | ~ 参考 | 最暗处（下巴下方/颈部投影），美漫常直接压近黑 |
| `blush` | `#D98A7A` | ~ 参考 | 腮红（美漫里更克制，可选） |
| `dress` | `#DCDEE0` | ✔ 量出 | 白裙，略偏冷 |
| `dress_shade` | `#A8AEB4` | ~ 调整 | 裙褶阴影**偏冷灰** |
| `dress_line` | `#3A3F45` | ~ 参考 | 裙子的线稿色 |
| `line_art` | `#241A18` | ~ 参考 | **线稿色**：不要用纯黑 —— 缩到 128px 会糊成脏块 |
| `eye_iris` | `#4A3226` | ✗ 推断 | 照片里眼睛太小，不是量出来的 |
| `lips` | `#C0705F` | ~ 调整 | 美漫唇色更实、更红一点 |

调整逻辑（不是随手改的）：

1. **高光改冷色**（`#5A6B7A`）：美漫上色用冷色打头发/皮肤高光，
   暖褐高光会立刻变成日漫观感
2. **阴影偏冷**：美漫阴影常用冷灰/蓝灰，`skin_shadow` 与 `dress_shade` 都往冷里调
3. **最暗处压近黑**：美漫敢用大面积实心黑，`hair_solid` / `skin_black` 就是为此
4. **线稿不用纯黑**（`#241A18`）：纯黑线在 128px 下会和暗部粘成一团

⚠️ `eye_iris` 是**推断值**（照片里眼睛太小），不是测量结果。

## 六、生成参数建议

| 项 | 建议 | 理由 |
|----|------|------|
| 画幅 | **4:5 或 3:4 竖构图** | 上半身是竖的；方形会有很多空白 |
| 分辨率 | **≥ 1024×1280** | 最终显示 127px，还要做多帧缩放 |
| 采样步数 | 28~35 | 平涂风格不需要太高，但太低线会断 |
| CFG / 引导强度 | 7~9 | 太低风格跑偏，太高线稿变脏 |
| 批量 | **一次生成 8 张** | 挑一张五官位置规整、没被头发遮的 |
| 模型倾向 | 美漫/动画类 checkpoint | 通用写实模型很难出对风格 |
| ControlNet | 可用照片做 **pose/构图**参考，强度 **0.3~0.5** | 高了会画成照片风；只借大形，不借长相 |

### 关于「像不像照片里的人」

**不要把照片喂进去做 img2img 高强度重绘** —— 那样出来的会偏写实，
和美漫风冲突。用 ControlNet 借**构图与姿势**，长相让模型按美漫风自己发挥。

如果你确实要「像她」，那需要的是**写实风格**的形象，与美漫画风二选一。
这一点请先定下来，否则会来回返工。

## 七、拿到图后先过这份清单

- [ ] **正面朝前**（不是背影、不是侧脸 —— 这是硬约束）
- [ ] 上半身，腰部以上，没有全身
- [ ] **眼睛与嘴完整可见**，没被头发遮住
- [ ] 背景纯色或透明，没有场景
- [ ] 没有水印、文字、签名
- [ ] 看样子是**平涂**而不是密集排线（放大看图，线条之间不该有细密斜纹）
- [ ] 分辨率 ≥ 1024×1280
- [ ] 角色居中，上下留白对称

**任何一条不过就重新生成** —— 拿回去重画比后面修补便宜得多。

> 最后一关（缩到 128px 看还认不认得出）我来做：
> 我会真的把它缩到 128×128 再放大检查，糊掉的会告诉你。
