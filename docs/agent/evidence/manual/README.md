# 人工验收证据目录（P4-A3）

放这里的是**人**做出来的证据：对着麦克风说话时截的图、录的屏、贴的控制台输出。
自动化（`tools/run_acceptance.py`）的证据不在这里，在
`docs/agent/evidence/acceptance/`。

## 命名规范

`<编号>-<场景>-<描述>.<扩展名>`，编号必须是下列之一：

| 编号 | 场景 | 至少几个文件 | 建议文件名 |
|------|------|------------|-----------|
| `M1` | 搜索文件 | 1 | `M1-搜索-结果气泡.png` |
| `M2` | 删除确认 | **2** | `M2-删除-预览气泡.png`、`M2-删除-回收站核实.png` |
| `M3` | 打断 | 1 | `M3-打断-现象.mp4` 或 `M3-打断-说明.txt` |
| `M4` | 降级路径 | 1 | `M4-降级-笑话.png`、`M4-降级-问候.png` |
| `M5` | 安全边界 | **2** | `M5-安全-拒绝气泡.png`、`M5-安全-审计记录.txt` |
| `G1` | GUI 观察点 | 1 | `G1-动效-待机转说话.mp4` |

其它文件（临时、重复、没用的）请删掉 —— 这个目录要能一眼看出"哪条做完了"。

## 结论

统一写在 `结论.md`，一条一行，形如：

```
M1 搜索文件 | 通过 | 确认语很快，报出的两个 PDF 都对
M3 打断     | 不通过 | 播报停了，但随后又念了一遍结果
```

判定词只认这四个：`通过` / `部分通过` / `不通过` / `未做`。

## 校验

```bat
python tools/check_manual_evidence.py
```

它只回答"证据齐了吗、结论写了吗"，**不替你判"过不过"**。缺哪条报哪条。

> ⚠️ **本目录里的 6 条全部完成之前，不得对外宣称"产品可用"。**
> 自动化能证明管线正确，证明不了"你说的话它听得见""气泡真的弹出来了""确认语听着自然"。
