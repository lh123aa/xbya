## 一、"完全闭环"的定义（本文件的判据）

**闭环 ≠ 100% 完成。闭环 = 每一条已登记项都有一个终态，且该终态可被检查。**

允许的四种终态，**没有第五种**（"以后再说"不是终态）：

| 终态 | 判定要求 |
|------|---------|
| ✅ **已修** | 有代码改动 + 有用例 + 过门禁 |
| ✅ **已实测** | 有原始输出留档，结论明确（**允许结论是"不可为"**） |
| ⬜ **明确不做** | 写明理由，且理由要能被反驳（不是"没时间"） |
| 🟡 **待人工** | 附**最小操作路径** + **可判定判据**；并说明为什么 AI 做不了 |

**为什么先定这个**：P4 结束时账面上还有 3 项没有终态（A3/B4/B1），
而 `f-closure.md` §17.4 里 7 条早已闭环的项还写着"未做" ——
**如果不先定义"闭环"，"完全闭环"就只能靠嘴说。**

### 2.6 B1（EventBus 适配层）的终态 —— 明确不做

`p4-plan.md` 的验收条件里，"契约一致"有两条路：**同一类型约束** 或 **适配层转换**。
现在的状态是**前者已经成立**：

- `core/app.py::_setup_agent_layer` 用的就是 `core.kernel.events.EventBus`；
- `tests/test_app.py:229` 断言 `app.agent_bus` 是内核总线类型；
- `agent/bootstrap.py::assert_kernel_bus` 把"接错"变成**装配期立刻抛错**（P4-B1 交付）。

剩下的只是"旧总线 `core.event_bus.EventBus` 仍然存在"。**不做适配层**，理由：

1. 它在 Agent 层路径上**已经没有使用者**，统一它属于**架构重构**而非闭环必需项；
2. `p4-plan.md` §六 把"是否接受该改动面"列为**人工决定**，用户上一轮已选"保留守护"；
3. 收益（消除一个不再被误用的类）< 风险（碰受 G12 保护的语音管路）。

**故 B1 的终态是 `明确不做（人工决定）`**，并在债务表里把 D14 记为"守护已交付 + 适配层不做"。

## 四、逐项验收标准（代码化）

### P5-A1 账本不再说谎

| 验收条件 | 判定方法 |
|---------|---------|
| 7 处落后全部刷新 | `f-closure.md` §17.4 用**复核段**方式追加（不重写原文 —— 沿用缺陷 12 的约定："核实后追加复核段，不再重复写勘误"） |
| 完成度说明连口径 | `AGENTS.md` 新增一节：口径内 100% 的是什么、**口径外**是什么、哪些待人工；**不给没有分母的百分比** |
| 可被检查 | G13 的证据路径检查覆盖 p5 清单；`check_manual_evidence.py --self-test` 可复跑 |

### P5-A2 D17 计划参数类型校验

| 验收条件 | 判定方法 |
|---------|---------|
| 类型不符的步骤被丢弃 | 用例：给一个 `pattern` 是列表、`source` 是列表、`targets` 套了一层的计划 → 这些步骤被丢，且**记日志说明丢了哪一步、为什么** |
| 不误伤合法步骤 | 用例：类型正确的多步计划**一步不少**（防"修到不能干活"） |
| 与工具真实 schema 一致 | 校验用**工具注册表的 `params_schema`**，不另写一份（本项目踩过"复刻判据"的亏） |
| 参数为 None 的可选字段不受影响 | 用例：`{"time_range": null}` 必须仍然放行（F 系列缺陷 4 的回归保护） |
| 全量回归 + 覆盖率 | P4-G1 / G2 |

### P5-A3 B1 终态

| 验收条件 | 判定方法 |
|---------|---------|
| 债务表写明终态 | D14 行改为"守护已交付 + **适配层明确不做**（附 3 条理由）" |
| 不装完成 | 措辞不得暗示"两个总线已统一"；必须说清旧类**仍在**且**仍在服务语音层** |

### P5-B1~B5

| 编号 | 判定方法 |
|------|---------|
| B1（D16） | 两种 schema 形制要么统一、要么由**类型/断言**约束；加一条守护用例：把注册表 schema 直接喂给 `chat_with_tools` 会被**显式拒绝或自动纠正**，而不是静默产生无名工具 |
| B2（voice_service 传参） | `voice_service` 与 `core/app.py` 两条加载路径**行为一致**；用例断言 ASR 参数确实透传 |
| B3（ST+vec0） | 真 ST 嵌入器（384 维）写入 + 检索一条记忆走通；维度变化时**索引被重建**且如实报告 |
| B4（medium 长句） | 同一批**长句**在 small/medium 下对比，给出数字；结论允许是"差异不明显" |

## 五、门禁与监督机制（沿用 P4，不新增口径）

| 关口 | 通过条件 |
|------|---------|
| P5-G0 | `py_compile` + 工作区干净（一次提交一任务，提交信息含任务编号） |
