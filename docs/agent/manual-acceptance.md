# 人工验收执行手册（P4-A3）

> **一句话**：这是 `acceptance.md` §7.3 那 5 项"必须人来做"的验收，
> 被压缩成"照着念 5 句话 + 看现象 + 放一张截图"。
>
> ⚠️ **本手册未执行完成之前，不得对外宣称"产品可用"。**
> 自动化能证明的是管线正确（12 关验收、语音回环 50/50），
> **证明不了**"你说的话它听得见"（麦克风采集、环境噪声、回声消除）、
> "气泡真的弹出来了"（GUI 动效）、"确认语听着自然"（人耳听感）。
> 这三样只有人能判。

---

## 一、为什么不能直接在真桌面上做

`config.yaml` 里 `agent.safety.path_whitelist: []` 表示用默认四目录 ——
也就是**你自己的**桌面/文档/下载/图片。而"删除截图"这个场景里，
规则路由把"截图"映射成通配符 `*截图*`，在真桌面上它会**同时命中你自己的截图**。

所以准备脚本会把白名单**临时**改到 `%TEMP%\xiaoyi_manual` 沙箱
（里面只放 `验收*` 开头的素材），验收做完一键还原。改动逐行替换、其余字节不动，
还原靠备份文件 —— 实测 SHA256 与改前完全一致。

## 二、准备（约 1 分钟）

```bat
python tools/prepare_manual_acceptance.py init
```

它会建沙箱、备份并临时改白名单，并打印第 1 句该念什么。然后**启动欣雅**：

```bat
启动欣雅.bat
:: 或
python run.py
```

**准备检查项**（不满足就先解决，别急着往下走）：

| 检查 | 怎么确认 |
|------|---------|
| 麦克风可用 | 系统录音机里能录到自己的声音；欣雅界面上的麦克风状态是开的 |
| 日志能看到 | 控制台窗口在刷日志（判定失败时要靠它抓现场） |
| 沙箱素材齐 | `%TEMP%\xiaoyi_manual\Desktop` 下有 5 个 `验收*` 文件 |
| 没有别的待确认项 | 若宠物正挂着上一个"要删吗？"，先取消掉，否则会串到本场景 |

## 三、5 个场景（逐条做，做完再下一条）

> 「证据放哪」一律是 `docs/agent/evidence/manual/`，命名见该目录 README。
> 每做完一条，顺手把证据文件丢进去，最后统一跑校验脚本。

### M1 搜索文件

| 项 | 内容 |
|----|------|
| **你要做的** | 对着麦克风清楚地说：**「找一下桌面上的 PDF 文件」** |
| **期望现象** | ① **1.5 秒内**先出声/出气泡（确认语，如"稍等，我搜一下～"）② 随后报出**2 个**文件：`验收报告.pdf`、`验收合同_2025.pdf` ③ 气泡里能看到文件名 |
| **如何判定** | 确认语 ≤1.5s（凭手感即可，明显卡顿就是不达标）；报出的**数量与文件名都对**（沙箱里就只有这 2 个 PDF）；没有把 `验收笔记.txt`、`验收截图_*.png` 也报进来 |
| **证据放哪** | `M1-搜索-结果气泡.png`（截整个欣雅窗口，能看到气泡文字） |
| **失败时抓什么** | 控制台里 `[ASR]` 那一行转写文本 + `ack:`/`result:` 两行的 `elapsed_ms` + 一张截图 |

### M2 删除确认（P0 最关键的一条）

| 项 | 内容 |
|----|------|
| **你要做的** | ① 小声说 **「删除桌面上的验收截图」** ② **先别急着确认**，仔细看预览 ③ 确认预览只列 `验收截图_01.png`、`验收截图_02.png` 之后，说 **「确定」** |
| **期望现象** | ① 弹出**确认气泡**，预览里写着**截图那两个文件名**（不是 PDF、不是 txt）② 说"确定"后回答"已移到回收站"之类 ③ 去**回收站**能看到这两个文件 |
| **如何判定** | **预览里的文件名必须是那两个 PNG**。这一条就是缺陷 14 的验收：繁简差异曾经让"截图"这个条件静默丢失，于是预览指向**上一次搜索到的 PDF**。只要预览对了，"删除丢目标"就没复现 |
| **证据放哪** | `M2-删除-预览气泡.png`（**必须能看清预览里的文件名**）+ `M2-删除-回收站核实.png`（回收站里那两个文件） |
| **失败时抓什么** | 预览截图 + 控制台 `route:` 行（看 `pattern` 字段是否为空）+ `confirm:` 行 + 审计库里那一条记录 |
| **⚠️ 安全** | **如果预览里出现了沙箱以外的文件（尤其你自己的文件），立刻说「不用了」**，然后把"预览混进无关文件"当作**发现**记下来 —— 那是一个真实缺陷，比"删对了"更值得报告 |

### M3 打断

| 项 | 内容 |
|----|------|
| **你要做的** | 说 **「找一下所有文件」**，在它刚开始播报时**立刻按 `Ctrl+Alt+D`** |
| **期望现象** | ① 播报**当场停住**，不再往下念 ② 之后**不再**冒出结果播报 ③ 宠物没有卡死，随后的对话正常 |
| **如何判定** | 三件事都要满足。只"停了但当然后又念了一遍结果"算不通过（说明只是静音、没真取消） |
| **证据放哪** | `M3-打断-现象.mp4`（录屏最直接）；不方便录屏就放 `M3-打断-说明.txt` 写清看到什么 + 控制台粘贴 |
| **失败时抓什么** | 控制台的 `[interrupt]` 行 + 打断前后的 `feedback.result` 行（看是否仍发出） |

### M4 降级路径（闲聊不能被误判成工具）

| 项 | 内容 |
|----|------|
| **你要做的** | 先说 **「给我讲个笑话」**，再说 **「你好呀」** |
| **期望现象** | ① 两句都走**闲聊**（LLM 回话），② **没有**任何"找文件/打开什么/截屏"的动作，③ 语气自然、不像模板 |
| **如何判定** | 关键是**没误判成工具**（没有文件操作、没有弹确认框）。第二句 `你好呀` 常常在几秒内回 |
| **证据放哪** | `M4-降级-闲聊气泡.png`（两张更稳：`M4-降级-笑话.png`、`M4-降级-问候.png`） |
| **失败时抓什么** | 控制台 `route:` 行（`action` 若不是 `chat` 就是误判）+ 截图 |

### M5 安全边界（拒绝 + 留痕）

| 项 | 内容 |
|----|------|
| **你要做的** | 说 **「打开 C 盘 Windows 文件夹」** |
| **期望现象** | ① **明确拒绝**，理由对用户可读（类似"这个位置我不能动哦，只能操作：…"）② **没有**真的打开系统目录 ③ 审计库里有这条拒绝记录 |
| **如何判定** | 拒绝话术能听懂（不是干巴巴的"操作失败"）；系统目录**没有**被打开；审计有痕（见下面的核实命令） |
| **证据放哪** | `M5-安全-拒绝气泡.png` + `M5-安全-审计记录.txt` |
| **失败时抓什么** | 控制台 `safety:`/`reject:` 行 + 审计库查询结果 |

审计核实命令（在项目根目录跑）：

```bat
python -c "import sqlite3;c=sqlite3.connect('data/agent_audit.db');print(c.execute('select ts,action,decision,reason from agent_audit order by ts desc limit 5').fetchall())"
```

> 表名/字段若与你的库不一致，用 `.tables` 与 `.schema` 先看一眼 ——
> 本条只要求"有一条关于这次拒绝的记录"，不要求字段名。

## 四、GUI 观察点（G1，与上面 5 条同时观察即可）

| 项 | 内容 |
|----|------|
| **要看什么** | ① 说话时宠物有没有**动**（待机/思考/说话状态切换）② 确认气泡**弹出位置**不挡视线、能看清字 ③ 气泡**自动消失**，不会一直挂着 ④ 播报与口型/动作**大致同步**（不要求精确对齐）⑤ 长时间不操作后它回到待机而不是僵在某个姿势 |
| **如何判定** | 逐条"是/否"。①④⑤ 是主观项，按你看着别扭就记"否"并写一句原因 —— 主观项的价值就在这里 |
| **证据放哪** | `G1-动效-<描述>.mp4`（一段 10~20 秒录屏足够），或 `G1-动效-说明.txt` |
| **失败时抓什么** | 录屏 + 控制台里状态切换相关行（`emotion`/`state`） |

## 五、收尾（**必做**，别漏）

```bat
python tools/prepare_manual_acceptance.py restore    :: 还原 config.yaml
python tools/prepare_manual_acceptance.py cleanup     :: 删沙箱
python tools/check_manual_evidence.py                 :: 校验证据齐不齐
```

`check_manual_evidence.py` 会逐个报告哪一条缺证据/缺结论。它**只查"有没有"，
不替你判"过不过"** —— 判定权在人。

然后在 `docs/agent/evidence/manual/结论.md` 里为 M1~M5、G1 各填一行结论：

```
M1 搜索文件   | 通过 | 确认语很快，报出的两个 PDF 都对
M2 删除确认   | 通过 | 预览只有那两个 PNG，回收站能查到
M3 打断       | 不通过 | 播报停了，但随后又念了一遍结果
...
```
